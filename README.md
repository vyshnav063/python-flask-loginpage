# Flask Login & Registration Portal

## Project Description

This project is a Login and Registration Portal developed using Python and Flask. It allows users to register an account, log in securely, access a dashboard, and log out.

The project demonstrates basic web development and authentication concepts using Flask, HTML, CSS, Jinja2, SQLite, password hashing, and session management.

## Technologies Used

- Python
- Flask
- HTML5
- CSS3
- Jinja2
- SQLite
- Werkzeug
- Git
- GitHub
- Visual Studio Code

## Features

- User registration
- Secure login
- Password hashing
- Session management
- Protected dashboard
- Logout functionality
- Form validation
- SQLite database
- Responsive web interface

## ⚙️ Installation

### 1️⃣ Clone the Repository
```bash
  git clone https://github.com/vyshnav063/python-flask-loginpage.git
```

### 2️⃣ Navigate to the Project
```bash
cd python-flask-loginpage
```
### 3️⃣ Create a Virtual Environment
```bash
python -m venv .venv
```

### 4️⃣ Activate the Virtual Environment
Windows:
```bash
.venv\Scripts\activate
```
### 5️⃣ Install Dependencies
```bash
pip install -r requirements.txt
```

### ▶️ Usage

- Run the Flask application type the terminal: python app.py
  
- Open your browser and visit: http://127.0.0.1:5000


Then you can:
-📝 Register a new account
-🔑 Log in with your credentials
-👤 Access the dashboard
-🚪 Log out
